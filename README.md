# Markdown Notes CLI

A lightweight Python terminal app for creating, listing, reading, and deleting Markdown notes.

## Run
```bash
python main.py
```
Notes are stored locally in `notes/`. No external packages or internet connection are required.

## Features
- Create Markdown notes
- List and read saved notes
- Delete a note by number
- Simple input validation
